# Devin Telegram Bot

Telegram бот для управления сессиями [Devin AI](https://devin.ai) с поддержкой множества API ключей и автоматической ротацией при исчерпании лимитов.

## Возможности

- **Создание сессий Devin** — запускайте задачи для AI-разработчика прямо из Telegram
- **Общение с сессиями** — отправляйте сообщения, фото, файлы в активную сессию
- **Мульти-ключ** — добавляйте несколько API ключей, бот автоматически переключится при лимите
- **Авто-ротация** — при ошибке 429/401/403 бот пробует следующий ключ
- **Вайтлист** — доступ только для разрешённых Telegram ID
- **Админы** — управление ключами и пользователями
- **Снимки сессий** — `/snapshot` для получения последнего скриншота из Devin
- **Полный лог** — вся история действий доступна владельцу бота
- **AI чат** — общение с GPT, Claude, Gemini, GLM прямо в боте
- **Голосовые команды** — управление ботом голосом

## Команды бота

### Сессии
| Команда | Описание |
|---------|----------|
| `/newsession <задача>` | Создать новую сессию Devin |
| `/session` | Текущая активная сессия |
| `/status` | Статус текущей сессии |
| `/sessions` | Список всех сессий |
| `/switch <id>` | Переключить на другую сессию |
| `/delsession <id>` | Удалить сессию |
| `/snapshot` | Скриншот/снимок текущей сессии |
| `/devin` | Все сессии на аккаунте Devin (админ) |
| *текстовое сообщение* | Отправить в текущую сессию |

### API ключи (админ)
| Команда | Описание |
|---------|----------|
| `/addkey <ключ> [название]` | Добавить API ключ |
| `/keys` | Список ключей |
| `/removekey <id>` | Удалить ключ |
| `/switchkey` | Переключить на следующий ключ |
| `/switchkey <id>` | Переключить на конкретный ключ по ID |
| `/exportkeys` | Экспорт ключей в файл |

### Вайтлист (админ)
| Команда | Описание |
|---------|----------|
| `/adduser <tg_id> [admin]` | Добавить пользователя |
| `/removeuser <tg_id>` | Удалить пользователя |
| `/users` | Список пользователей |
| `/broadcast <текст>` | Рассылка всем пользователям |

### Прочее
| Команда | Описание |
|---------|----------|
| `/menu` | Главное меню с кнопками |
| `/cost` | Расход по ключам и пользователям |
| `/log [страница]` | Полный лог действий (только владелец) |
| `/chat` | AI чат (GPT/Claude/Gemini/GLM) |
| `/stopchat` | Выйти из AI чата |
| `/myid` | Показать ваш Telegram ID |

## Деплой на Railway

### 1. Переменные окружения

В Railway добавьте переменные:

| Переменная | Описание |
|-----------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `DB_PATH` | Путь к БД (по умолчанию `/data/bot_data.db`) |
| `OPENAI_API_KEY` | *(опционально)* Для распознавания голоса через Whisper |

### 2. Деплой

```bash
# Подключите репозиторий к Railway
# Railway автоматически подхватит Dockerfile и railway.toml
```

### 3. Первый запуск

1. Напишите боту `/start` — первый пользователь автоматически станет админом
2. Добавьте API ключ: `/addkey apk_user_xxx МойАккаунт`
3. Создайте сессию: `/newsession Напиши hello world на Python`

## Получение API ключа Devin

1. Зайдите на https://app.devin.ai
2. Settings → API Keys
3. Нажмите "Generate API Key"
4. Скопируйте ключ (показывается один раз!)

## Локальный запуск

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
pip install -e .
python bot.py
```
